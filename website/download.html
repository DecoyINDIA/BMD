The browser extension

It hands your browser's downloads to BMD with their cookies, adds Download with BMD to the right-click menu and puts a Download video button over videos.

Firefox (and Zen, LibreWolf): not available yet. Firefox installs only add-ons that Mozilla has signed, and BMD's is not listed on addons.mozilla.org yet.

Chrome, Edge, Brave, Opera, Vivaldi and Helium use the bundled extension in the app's extension folder. You can also download the Chromium extension ZIP and unzip it. Follow the step-by-step guide to load it.

Install in three steps

  1. Download setup.exe above and run it. Windows may ask whether to allow it: the installer isn't code-signed yet, so choose More info → Run anyway.
  2. Pick your language and keep Set up browser integration ticked.
  3. Start BMD from the Start menu, then download your first file.

With WinGet, Windows' package manager: in a terminal, the first line installs BMD and the second updates it.

winget install DecoyINDIA.BMD
winget upgrade DecoyINDIA.BMD

On Linux or a Mac

Linux: install the .deb with sudo apt install ./<file>.deb (Debian, Ubuntu, Mint) or the .rpm with sudo dnf install ./<file>.rpm (Fedora), and the packages bring what BMD needs. Or make the AppImage executable (chmod +x) and run it. BMD connects itself to your browsers at each start; then add the extension from your browser's store, above. More in the help.

macOS: open the .dmg and drag BMD to Applications, then right-click it and choose Open the first time.

Linux isn't experimental any more, since version 0.5.0. GNOME, KDE Plasma, Xfce and Cinnamon are checked window by window, with the tray and light and dark modes, in Wayland sessions too, and the .deb and .rpm in clean Ubuntu 24.04, Debian 12 and Fedora 45 systems. What's left: the Flatpak Firefox isn't checked yet, and screen readers (Orca) don't read BMD's windows on Linux yet. macOS stays experimental. Windows, Mac and Linux

Get it safely

BMD is free and open source, for everyone. There is no premium, pro, "MOD", paid or cracked version of it: nothing to buy and nothing to unlock. A copy sold or "unlocked" under its name isn't ours.

Community packages, such as the AUR and Nix ones, are made by volunteers, not by us. Copies on other download sites, cloud drives or in chat groups aren't ours either. Wherever a copy comes from, you can check it.

Check your download

  1. From the release, download SHA256SUMS.txt, the SHA-256 checksum of every file.
  2. Get your file's checksum: on Windows with certutil -hashfile file SHA256, on macOS and Linux with shasum -a 256 file. It must match the file's line in SHA256SUMS.txt.
  3. To be sure the file was built by us, check its build provenance with the GitHub CLI: gh attestation verify file --repo DecoyINDIA/BMD. It should say the file was built by this repository's release workflow.

Every file is built from the public source by GitHub Actions; the build logs are on GitHub.

If Windows or an antivirus warns

The installer isn't code-signed, and each new version is new to Windows, so SmartScreen may show Windows protected your PC until enough people have run it. Choose More info, check that the file is BMD-{{VERSION}}-setup.exe, then Run anyway.

A few antivirus programs, mostly machine-learning engines, flag new installers they have rarely seen. On VirusTotal, a handful of small engines flagging the setup while the big ones stay clean is usually a false positive. If the checksum matches, it is the file we published; if something still looks wrong, tell us on GitHub. More in Troubleshooting.
