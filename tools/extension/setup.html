Install the BMD extension

  1. Open a new tab and enter the address for your browser.
    • Chrome, Comet and other Chromium browsers chrome://extensions
    • Microsoft Edge edge://extensions
    • Brave brave://extensions
  2. Turn on Developer mode and choose Load unpacked.
  3. Select the folder containing this guide and manifest.json. If you opened the guide from BMD, the folder path is already copied.

After BMD appears in the extensions list, open its toolbar popup to check the connection.
